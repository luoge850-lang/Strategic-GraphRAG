## 实际修复的根因

- **答了另一事实却成功**：目标指标和槽位现在共同使用非重叠的语义匹配；累计其他综合收益余额、其他综合收益流量与综合收益总额具有不同身份。原H03现在返回余额28 USD millions，引用2025年报物理页54，浏览器实际点击原文已核对。
- **归因条件丢失**：事件造成/归因于事件的营收损失不能变成年度总营收；未识别的accumulated/deferred/unearned/unrealized等具体财务修饰不能悄悄降格为总额。无证据的归因题保留明确拒答，而有来源的普通财务题继续执行。
- **可答题被句式拦截**：来源尾句中的现金流量表/资产负债表、上下文前置逗号、完整会计名称中的loss/net/tax逗号、已识别现金流调整的变动身份得到处理，不再把这些条件当未知额外指标。
- **原文覆盖不足**：从原PDF抽取退休计划费用的respectively对应、当前联邦税与递延税分组、股权薪酬现金流调整、带符号股息现金流、Networking收入分项及图形分部营业利润。没有硬编码参考数字或特定审查问题，依赖原文标题、列年、行数和单位。
- **同名行冲突**：递延税明细中的“Operating lease assets”是该资产的税务影响，不是公司资产余额；相关候选进入隔离，避免它与真实1793资产余额冲突，也避免直接替代余额。拆行日期不再跨列拼出虚假的月日/年份，不能确定时保留UNKNOWN。
