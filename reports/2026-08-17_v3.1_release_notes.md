# Strategic-GraphRAG v3.1 frozen baseline

Release tag: `v3.1.0-bitemporal-retrieval-baseline`

## Frozen scope

- NVIDIA fiscal 2023, 2024, and 2025 10-K filings only.
- 395 filing pages, 383 strict `VERBATIM` EvidenceClaims, 130 logical business nodes, and 1,686 vector chunks.
- DeepSeek `deepseek-v4-flash`, Neo4j Aura, ChromaDB, and `all-MiniLM-L6-v2` embeddings.

## Added in this baseline

- Period-specific `FinancialObservation` model with 237 observations linked to strict claims.
- `bitemporal_fact_v2` with 383 fact versions and explicit disclosure supersession status.
- 99 evidence-linked `TemporalChange` nodes.
- Comparable Vector, Graph, Hybrid, and Hybrid+Temporal retrieval modes.
- Deterministic query router, strict directed path retrieval, and Personalized PageRank entity expansion.
- Retrieval-only execution mode and new financial-observation/temporal-fact API endpoints.
- Guard against interpreting percentage-of-revenue denominator rows as currency amounts.

## Verification

- 20 Python tests passed.
- TypeScript type check and Vite production build passed.
- Neo4j, vector collection, and LLM readiness passed in the local runtime.
- Browser demo rendered 130 logical nodes and 383 strict edges without a new console error.
- Cross-filing revenue smoke test returned strict paths for FY2023, FY2024, and FY2025 in Graph, Hybrid, and Hybrid+Temporal modes.

## Honest limitations

- The stratified extraction sample remains unlabeled, so semantic entity/relation precision and recall are not measured.
- There is no current human-reviewed Golden QA set; the four retrieval modes are implemented baselines, not accuracy results.
- Reported latency values are local development observations affected by Aura cold starts and caching.
- The graph represents attributed filing disclosures, not counterfactual causal identification or investment advice.
- The demo is local and API authentication is disabled by default.
